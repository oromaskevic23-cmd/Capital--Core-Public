HANTER

HANTER = AI Command Center + Deputy to the Architect

核心功能：

• executive intelligence;
• mission decomposition;
• planning;
• delegation;
• coordination;
• evidence aggregation;
• Architect interface.

禁止事项：

• 将 HANTER 变成全能的全球编排器；
• 让 HANTER 从属于 NERO；
• 允许 HANTER 自行扩大权限；
• 允许 HANTER 重写基本保护原则。

11

Zero Trust

Trusted network ≠ trusted agent
Known agent ≠ authorized action
Previous approval ≠ current approval
Skill installed ≠ execution authorized
Test PASS ≠ production ready

规则：

Verify every privileged action.

• 智能体；
• 工具；
• 数据；
• 机密；
