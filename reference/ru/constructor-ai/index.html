05 / SECURITY

Управляемая разработка

Существующая Federated Multi-Orchestrator Architecture сохранена. AI Passport идентифицирует агента; Guardian Core проверяет политики; Approval Gateway контролирует действия, требующие согласования; Runtime Domains изолируют исполнение; Audit Ledger фиксирует доказательства. Идентификация не предоставляет полномочия. Код модели должен пройти тесты в изоляции. Production-публикация требует одобрения владельца.
